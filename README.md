# Whisper-large-v3-docker-gpu
Собственный сервис преобразования речи в текст на основе Faster-Whisper с поддержкой графического процессора NVIDIA и пользовательским интерфейсом Gradio.

# Whisper Large V3 Russian: Локальный сервер распознавания речи (Docker + NVIDIA GPU)

Этот проект представляет собой готовое к развертыванию решение для автоматического распознавания речи (ASR) на базе модели **Whisper Large V3**.

Система упакована в Docker-контейнер, оптимизирована для работы с видеокартами NVIDIA и имеет встроенный веб-интерфейс для демонстрации и тестирования.

## 🚀 Возможности
- **Высокая производительность:** Используется движок `faster-whisper` (CTranslate2), который работает в 4-5 раз быстрее оригинального OpenAI Whisper.
- **Поддержка GPU:** Полная утилизация ядер CUDA (NVIDIA). Протестировано на RTX 3090.
- **Приватность данных:** Работает полностью **локально** (Self-Hosted). Аудиофайлы не отправляются в облако, интернет нужен только при первом запуске для загрузки весов модели.
- **Веб-интерфейс:** Встроенная панель управления на базе Gradio для быстрой проверки гипотез и демонстрации заказчику.
- **Поддержка Русского языка:** Используется модель Large-v3, обеспечивающая высочайшее качество распознавания русской речи, включая сложные термины и акценты.

## 🛠 Технические требования
Для запуска требуется сервер или рабочая станция со следующими характеристиками:
- **ОС:** Linux (Ubuntu 20.04+) или Windows с WSL2.
- **GPU:** NVIDIA с поддержкой CUDA (рекомендуется от 8 ГБ VRAM для режима float16, или от 4 ГБ для int8).
- **ПО:** Docker Engine + NVIDIA Container Toolkit.

## 📦 Установка и Запуск

### 1. Подготовка
Убедитесь, что у вас установлен Docker и драйверы NVIDIA.
Склонируйте репозиторий (или создайте папку с файлами проекта):

```bash
git clone https://github.com/ВАШ-НИКНЕЙМ/whisper-large-v3-docker.git
cd whisper-large-v3-docker
```

### 2. Сборка Docker-образа

Соберите контейнер. При первой сборке будут загружены необходимые системные библиотеки (PyTorch, CUDA, ffmpeg).

```
docker build -t whisper-web .
```

### 3. Запуск сервера

Запустите контейнер, пробросив GPU и порт веб-интерфейса:

```
docker run --rm --gpus all -p 7860:7860 whisper-web
```

После запуска перейдите в браузере по адресу: http://localhost:7860

## ⚙️ Настройки (Конфигурация)

Основные параметры находятся в файле app.py:

-   MODEL_NAME: По умолчанию systran/faster-whisper-large-v3. Можно заменить на medium или small для слабых видеокарт.
    
-   COMPUTE_TYPE:
    
    -   float16 - Максимальная точность (требует ~6-8 ГБ видеопамяти).
        
    -   int8 — Высокая скорость и экономия памяти (требует ~3-4 ГБ видеопамяти), минимальная потеря качества.
        

## 🔒 Безопасность и Внедрение

Данный контейнер готов к работе в закрытых контурах (без доступа в интернет).  
Для переноса на изолированный сервер (Offline Mode):

1.  Сохраните образ: docker save -o whisper-image.tar whisper-web
    
2.  Перенесите файл .tar на целевой сервер.
    
3.  Загрузите: docker load -i whisper-image.tar
    

## 🤝 Потенциал развития (MCP)

Архитектура позволяет легко трансформировать этот веб-сервис в **MCP-сервер** (Model Context Protocol) для интеграции с LLM-агентами, голосовыми помощниками и системами аналитики.
